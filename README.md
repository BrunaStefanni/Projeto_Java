# Projeto_Java
Projeto desenvolvido para avaliação intermédia do curso UC00619 – Desenvolver aplicações em linguagem JAVA.

## Teor
Atividade consiste na construção de uma aplicação java, orientada a objetos, coleções, tratamento de exceções e ficheiros.

## Tema
Escolhi construir uma aplicação simples como um planner organizacional. Uma aplicação que permite o registro das minhas tarefas pessoais, divididas em categorias: faculdade, projetos, vida pessoal e treinos.

## Objetivo
Simples - ajudar o utilizador a organizar as suas responsabilidades e atividades em um único lugar.

> Nota 1: Até o momento, criamos a Class Tarefa.java, ativamos os Construtores e adicionamos a Interface Concluível.java e concectamos com a classe filha TarefaFaculdade.java
